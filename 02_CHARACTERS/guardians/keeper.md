# Character Summary

Aster คือผู้ดูแลหมู่บ้านของหาย

เขาเป็นผู้ที่คอยรักษาสมดุลระหว่าง

"สิ่งที่ควรถูกส่งคืน"

และ

"สิ่งที่ควรถูกปล่อยให้หายไป"


สำหรับคนในหมู่บ้าน

เขาเป็นทั้งผู้ปกป้องและผู้ตัดสิน


แต่สำหรับโน

เขาคือคนที่ดูเหมือนจะรู้เรื่องอดีตของเขามากกว่าที่ควรจะเป็น
