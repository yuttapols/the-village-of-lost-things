# Lost Object Characters


# Introduction

Lost Objects คือสิ่งมีชีวิตที่เกิดขึ้นจากสิ่งของ
ความทรงจำ และความรู้สึกของมนุษย์

บางตัวเป็นเพียงสิ่งของที่ถูกลืม

แต่บางตัวกลายเป็นผู้มีชีวิต
และมีหน้าที่ปกป้อง Lost Village

# Character Summary

คาบินาร่า หรือ "คาบิ"

เป็นสิ่งมีชีวิตปริศนาที่อาศัยอยู่ใน Lost Village

เขาเป็นเพื่อนคนแรกของโนหลังจากเข้ามายังโลกแห่งของหาย


ภายนอกเขาดูเหมือนสิ่งมีชีวิตที่ไม่มีพิษมีภัย

ตัวกลม
เดินช้า
ชอบนอน

แต่ความจริงแล้ว

เขาคือหนึ่งในผู้พิทักษ์ของหมู่บ้าน

# Hidden Personality


ถึงแม้ภายนอกจะดูขี้เกียจ

แต่คาบิเป็นคนที่มีความรับผิดชอบสูง


เมื่อเกิดอันตราย

เขาจะเปลี่ยนเป็นคนละคน


เขาจะ:

- ปกป้องเพื่อน
- ต่อสู้โดยไม่ลังเล
- ใช้พลังเต็มที่


---

# Ability


## Guardian Power

พลังป้องกัน Lost Village


สามารถสร้าง:

- โล่ป้องกัน
- กำแพงพลังงาน
- เขตปลอดภัย


---

## Lost Sense

สามารถรับรู้สิ่งผิดปกติในหมู่บ้าน


เช่น:

- สิ่งของที่กำลังสูญเสียตัวตน
- ผู้บุกรุก
- ความผิดปกติของ Lost World

# Relationship With Noah


## First Meeting
